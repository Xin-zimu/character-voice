## 工具：真实试聊

| 工具 | 用途 |
|---|---|
| `qoder_backend.mjs` | 可选后端：把本机 Qoder 连接器暴露成 OpenAI 兼容端点 |
| `scripts/live_chat.py` | 跑真实试聊并写 `out/live-chat-<时间戳>.md` |

用法：

```powershell
py server.py                                   # 一个窗口
node qoder_backend.mjs                         # 可选后端，另开窗口
py scripts/live_chat.py --server http://127.0.0.1:8770 --backend qoder --model dfmodel
```

也可以 `--base-url https://api.deepseek.com/v1 --api-key sk-...` 直接用自己的 Key。

**可选后端怎么工作**：`server.py` 的 `/api/backends` 读 `~/.dsh/qoder-backend/state.json`，并真的连一次 `/v1/models` 确认端口还活着（文件在≠进程在）。地址与 token 由服务端解析，**前端只传 backend id**，不接受前端指定地址，避免被指向别处。

**脆弱点**：它依赖插件内部构建产物（`lib/variants-*.js`，导出名是压缩后的单字母，所以按函数名 `createQoderTransport` 查找）。插件升级或改打包方式后可能失效——失效时明确报错，不静默降级。
