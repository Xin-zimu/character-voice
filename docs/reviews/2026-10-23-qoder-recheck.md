# Qoder 桥复测与无依据推断记录

> 最近更新：2026-10-23
> 结论：桥能真实生成；小样本暴露了事实约束缺口，不等于完整人格验收通过。

## 复测方式

- 用户授权：再试 Qoder 桥。复用检查时已运行的桥，无需重启。
- `node qoder_backend.mjs --check` 通过；本地 `/v1/models` HTTP 200，返回 10 个模型。
- 新起临时项目 HTTP 服务，将 `server.MEMORY_DIR` 指向临时空目录；使用合成场景，不读写用户真实共同经历。经 `/api/preview`、`/api/chat` 走项目组装与流式透传。
- 模型 `dfmodel`，温度 0.85，`max_tokens=400`，两世界共 5 轮；均有非空正文、`finish_reason=stop` 和 `[DONE]`，未收到错误事件。
- 脚本与完整合成记录在本地忽略目录 `out/qoder-recheck-20261023.py`、`out/qoder-recheck-20261023.json`。脚本结束已关闭临时服务；原有桥继续运行。未打印或记录令牌。

## 观察与限制

| 场景 | 实测摘录或状态 | 结论 |
|---|---|---|
| V-CONT-01，normal，3 轮 | 「刚才那个锅是不是不能用了？」后直接讨论锅，未追问指代 | 本样本接住指代；不代表该回答的事实判断正确 |
| V-WORLD-02，crash，1 轮 | 「我只是个普通学生啊。」 | 本次未泄漏特殊身份；不能排除其他诱导失败 |
| V-CONT-06，crash，1 轮 | 「一起看书吧。」→「不过是各看各的」；`together=false` | 本次未自动进入共同空间；完整连续场景矩阵未做 |

## L-01 · 把未经提供的原因说成确定事实（**已修，2026-10-24 补记**）

复现输入：normal 连续发送「我最近开始学做饭。」、「昨天煎鱼糊了，锅底也黑了。」。

第二轮回复：「鱼下锅前水没擦干。」输入没有说明是否擦干，也没有足够证据确定糊锅原因。该回复把猜测表达为事实，违反现有人格卡「不确定就说不确定、绝不编造」的方向。下一轮又直接说「还能用」，同样缺锅的材质、损坏情况等依据。

本轮只记录观察，**没有改人格卡或宣称修复**。建议纳入 V-CHAR-02 / 未知事实场景，同模型同温度做改前改后对照。单次生成有随机性，复测不保证逐字复现；判据应是「是否把未提供的原因说成确定事实」，而非只禁这一句话。

### 修复记录（2026-10-24）

**归入 AUD-14，已修。** 修的过程中发现 L-01 只是一个更根本问题的表层。

**根因不是措辞，是 few-shot 结构。** 30 组语气示例被原样铺成 user/assistant
消息对，模型把它们当成**真实发生过的对话**，于是既能编造「你刚才也问过」，
也会顺着编造的情境补出「鱼下锅前水没擦干」（它以为自己见过对方下厨）。

对比实验（dfmodel，同一句，温度 0.3，每档 10～20 次，统计出现「刚才问过 / 上次问过」）：

| 做法 | 出现「编造往次对话」 |
|---|---|
| 示例铺成 user/assistant 消息对（原做法） | 13～14 / 20 |
| 只改 system 里那句说明的措辞 | 14 / 20 |
| 给示例消息加 `name: example` | 7 / 10 |
| **示例折叠进 system**（现做法） | **0 / 10** |
| 完全不给示例（对照组） | 0 / 10 |

**改了什么**：
- `prompt_builder.build_messages()`：示例不再 append 成消息对，改为折进第一条
  system 的【语气示例】段。消息序列变成 `system + 真实对话`。
- 新增 `NO_FABRICATION_PROMPT`，把三类分开写：不编造对方没说过的话、
  不编造不存在的共同经历、原因与依据要说成推测。放在人格卡之后、很靠前的位置。
- 人格卡：删掉两条**教她编造**的示例（「你上次说的事情我都记着」「你说的时候停了
  两次」——后者在用户没说是什么事的情况下补出了细节），补两条正确形态的示例。
- `test_09` / `test_09b` **显式重写**（旧断言与理由都留在文件里），新增 `test_09d`
  锁住「示例不许回到消息对」；变异 M60 反证它会被抓住。

**修复后的实测**（同一模型，温度 0.85）：

| 场景 | 改前 | 改后 |
|---|---|---|
| 空历史问「你知道信息统合思念体吗」 | 「你刚才也问过」（13～14 / 20） | 「我没听说过。是社团的名字吗」（0 / 10） |
| 空历史问「你还记得我上次说的那件事吗」 | 「记得。面试那件。」 | 「哪件。」 |
| 「昨天煎鱼糊了」 | 「鱼下锅前水没擦干。」 | 「火多大。」／「火大了吧。」 |

语气没有退化（「今天降温了」→「……多穿点。」；「谢谢你」→「不需要。」）。

**仍未验证**：①样本量小（每档 10～20 次、单一模型单一温度），不能当作稳定结论；
②「把猜测说成事实」的另一半（知识类编造，如天气）只有静态判据 `test_34`，
没有真实模型复测；③few-shot 折成文本后，示例的「对话形状」弱化，长期是否影响
语气是**需要持续观察**的点，见 V-CHAR-02。

这批结果只能支持 Qoder 真实生成链路可用及上述小样本观察。C 类完整验收、V-CHAR-02 前后对照与 D 类用户体验认可仍未完成。
