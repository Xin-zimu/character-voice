# 共同经历（长期记忆）

这个目录存的是**你和「她」之间**记下来的事，每条按世界分开。

| 文件 | 内容 |
|---|---|
| `memory-normal.json` / `memory-crash.json` | 记录本体，含版本与纠正链 |
| `*.json.bak` | 每次写入前的上一版，主文件损坏时用来恢复 |
| `*.log.jsonl` | 操作日志，一行一个事件（新增 / 改 / 删 / 恢复 / 纠正） |

这些东西**不进公开仓库**（见根目录 `.gitignore`）：它是使用者的私人内容。
换机器时要自己把整个目录拷过去，否则「她」会忘掉你们之间发生过的事。

写入方式见 `memory.py`：临时文件 + `fsync` + `os.replace`，中途失败不会留下半条记录。
界面上点右上角 `◈` 可以查看、修改、删除和恢复。
