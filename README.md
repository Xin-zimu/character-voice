# 长门有希 · 文字助手（YUKI.N&gt; 终端）

> 第 06 集 13:24，阿虚的显示器亮起来，屏幕上出现 `YUKI.N>能看到吗？`。
> 她不在这个房间里。信号是从另一个世界挤过来的。
>
> 这个项目做的就是这个界面。

一个和长门有希**持续相处**的文字聊天项目。你和一个在另一条世界线上的她，通过一块终端屏幕通讯。

不是通用助手，也不是酒馆式角色扮演。

## 跑起来

**本仓库不包含字幕语料**（版权原因）。克隆后需要自备字幕，否则检索为空——程序能跑，但不会有原作片段。

> 本机开发时，语料与 BM25 索引单独放在**私有仓库** `Xin-zimu/character-voice-corpus`（不含在本公开仓库里）。克隆回来把 `parsed/`、`index/`、`scenes/`、`_deprecated/` 拷进 `data/` 即可，还原步骤见该仓库的 README。

```powershell
cd character-voice
# 1. 把解析好的字幕放进 data/parsed/*.dialogue.jsonl（格式见 data/README.md）
py build_corpus.py         # 建索引
py server.py
```

没有语料也能启动：检索退化为「无原作片段」，她只凭人格卡回答。回归测试同样降级——依赖语料的用例会**跳过并说明原因**，前端与 HTTP 链路测试照常运行。

默认地址 **http://127.0.0.1:8766**。端口被占用会在后续 9 个端口内自动顺延，以启动输出的地址为准。

点右上角 ⚙ 填 API Key（DeepSeek / 阿里百炼 / 硅基流动 / 本地 Ollama 都行）。Key 只存在浏览器 localStorage，不落盘、不上报。

### 可选后端：用本机的 Qoder 账号

装了 `dsh-qoder-connect` 插件并且已登录的话，可以不开 API Key，直接用它的额度：

```powershell
node qoder_backend.mjs        # 另开一个窗口，保持运行
py server.py
```

网页会自动接上，不用去设置里选。

它和插件一样是**外挂件**：项目本身不依赖它，没装插件就用 ⚙ 里自己的 API Key。它把插件的 loopback 端点换成固定地址暴露出来，复用插件自己的凭证与签名逻辑。**依赖插件的内部构建产物**，插件升级后可能失效——失效时设置面板会直接显示原因，不会静默失败。详见 [DEC-009](docs/DECISIONS.md)。

> PowerShell 自选起始端口：先 `$env:PORT='8770'`，再 `py server.py`。
> 需要走系统代理时：`py server.py --use-env-proxy`。

|---|---|

## 已经按产品方向改掉的旧行为

这一节原本列的是「现在确实是错的、但要改」的行为。到 2026-10-23 为止**原先那一栏已经清空**——下面几项都改完了。新的偏离项一旦出现会补回这里，进度见 [docs/STATUS.md](docs/STATUS.md)。

> **2026-10-23 补记**：原来这里写「这一栏已经清空」。合入 ZIP 版本后重新实测，查出 8 条已复现的缺陷，
> 其中三条直接影响下面列着的「已完成」功能（共同经历、场景状态、字符画格式）。
> 它们**不是**「方向改了但还没实现」，而是**已经写好的代码有 bug**，所以登记在
> [docs/reviews/2026-10-23-zip-merge-review.md](docs/reviews/2026-10-23-zip-merge-review.md)，
> 不重复写进这一节。这一节只讲「和产品方向相反的旧行为」，那部分确实清空了。

> **已完成的六项**：
> - **字数上限已取消**（2026-10-21）。人格卡不再有 `max_chars`，前端与自检也不再判定超长——长回复不会因长度被标 `△`、截断或重写。
> - **跨世界已严格隔离**（2026-10-21）。检索只在当前世界内进行，另一世界的片段不注入、不标注、不暗示。
> - **括号动作已开放**（2026-10-23）。`（）` 可以写动作、表情和少量情绪反应，也允许整条只有动作；要说的事必须写进正文。见 [CHAT-007](docs/PRODUCT.md)、[DEC-005](docs/DECISIONS.md)。效果（会不会每句都挂一个动作）**尚未试聊验证**。
> - **字数统计搬进调试面板了**（2026-10-23）。主聊天区不再有「N 字」和底栏统计，回复下只留 `△` 违例提示和「重说」。`◇` 面板改成三块：字数与违例统计、**上一次实际发送**（真正发出去的 payload 快照、历史、服务端回报的命中数）、**下一次预览**（用当前输入框重新组装，明确写着「不是上面那次实际发送的内容」）。见 [CHAT-006](docs/PRODUCT.md)。
> - **共同经历可以记下来了**（2026-10-23）。右上 `◈` 里写下的事会存进服务端（`data/memory/`，两个世界各一份），对话时按当前世界检索、作为独立的「共同经历」块注入，和原作片段来源分开。可以改措辞、换成新说法（旧的进回收站）、删、恢复，每一步都留操作记录。见 [CHAT-016](docs/PRODUCT.md)、[CHAT-018](docs/PRODUCT.md)。**目前只能手动记**——她不会自己从聊天里挑事记下来（参考方向已确认，自动抽取尚未实现，见 [PEND-008](docs/pending/DECISIONS-NEEDED.md)）；「她会不会自然地把旧事接住」也**尚未试聊验证**。

> **字符画只在崩溃世界放开**（2026-10-23）。崩溃世界的她可以画几行小图案，主线世界不带这个能力——主线有「一条回复只说一段，不要分两段」，再允许画图，形式规则会变成两套互相打架的规矩（[DEC-013](docs/DECISIONS.md)）。判定只看**内容本身**，两个世界同一套判据：什么时候算图案、画得歪不歪、前缀会不会吃掉缩进，都在 `textart.py` 里，前端有一份逐条对应的镜像，测试会逐例比对两端。**文字和图案混在一条里时按块排版**：只有图案那几行保空白，文字行照常折行。
>
> 两件没做完的事写在待决里，没有隐瞒：**字体**——实测本机 205 个已装字体里**没有一个**能同时满足「ASCII/框线/方块/盲文 全部 1 格」与「汉字正好 2 格」（`Cascadia Mono` 满足前者但汉字 1.77 格；`SimHei` 满足后者但框线全宽），所以方框会被拉长、盲文点阵会挤，要你选一条路（[PEND-010](docs/pending/DECISIONS-NEEDED.md)）；**生成方式**——用户已选择自由生成（[DEC-014](docs/DECISIONS.md)），现有模型回复可直接包含图案；自主选择与内容贴切性仍需试聊，不再等待模板选型。
>
> **她会自己画，但很少**（2026-10-26）。重数两轮真实采样：自然聊天 **32 轮里含图案块 1 次**（B2 turn2，画的是茶杯）。这不是「功能没通」，而是「时机难预测」——对照实验发现，删掉提示词里的劝阻句并不能提高出图率（0/8），只有写明「画出来比解释更省事」才会出现 1/8，而那种写法等于给了配额式触发，与 [DEC-007](docs/DECISIONS.md) 相反，所以不采纳。**「她什么时候会自然想画点什么」仍未查明**。

> **场景状态已经会记了**（2026-10-23）。她这侧会记住三件事：眼镜戴着还是摘下、手里的书开着还是合上、你们是不是同处一室。这些是**状态**不是事实——「摘了」之后再戴回去，前面那条就不算了。规则写得很窄：只认「明确的主语 + 明确的动作」，`（把眼镜摘下来）` 这种括号动作算（括号里是**她**的动作），你说「我摘了眼镜」不算你的、也不改她的；否定（「你别摘」）、假设（「如果你摘下」）、疑问（「你戴着眼镜吗」）一律不更新。没有记录的项目她不会提，也不会替它编一个。两个世界各记一份，切过去不继承。见 [CHAT-013](docs/PRODUCT.md)、[CHAT-008](docs/PRODUCT.md)。**「她会不会自然地用起来」尚未试聊验证**。

> **关于世界标签**：`◇` 面板里命中的片段带着当前的世界标签，但**这些标签本身未经审计**——它们按单一时间点切出来，不能当作归属正确的证据。见 [docs/STATUS.md](docs/STATUS.md) 的 BLK-001。

## 原作锚定

每句话发出去之前，服务端会：

1. 拿这句话去 13070 条原作台词里检索（BM25 + 近邻去重），**只在当前世界内检索**
2. 把命中的**完整对话上下文**（前后各 5 条）注进 system prompt
3. 让她把这些当记忆用——不复述、不念原文、不说「第几集」

**检索只做剧情锚定**：字幕没有说话人标注，所以只告诉她「这段对话里发生了什么」，不声称「这句是你说的」。准入要求的完整说明见 [data/README.md](data/README.md)。

**世界隔离**：另一世界的片段不会出现在 prompt 里——不注入、不标注、不给「你也许想起了什么」这类提示。这条是硬约束（[WORLD-001](docs/PRODUCT.md)、[DEC-002](docs/DECISIONS.md)）。

## 调参入口

人格全在 `personas/*.json`，改完刷新页面即生效，不用重启。

| 字段 | 作用 |
|---|---|
